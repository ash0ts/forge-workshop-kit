Change settings, then change architectures.
A configuration search changes settings in existing programs. Architecture comparison chooses an implemented model. Neither is an agent writing new research code.

Now let an agent edit the program.
Review the exact diff before execution. The agent’s rationale is a hypothesis. Probe it, compare the result, and keep the rejected branch. KEEP preserves the code fingerprint.

Freeze. Then open the reserved dates.
The final comparison loads saved weights and predicts. It does not train again. Look at the delivered prediction, not only the average score.
