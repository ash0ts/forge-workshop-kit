Reviewed November 15, 2026. These are instructional references, not assets to redistribute. All bundled drawings are original.

| Guide | Pattern used |
| --- | --- |
| [EP–35 update sequence](https://teenage.engineering/guides/ep-35#updating-ep-35) | One action, relevant part, and visible resulting state in each panel. |

| [OP–1 envelope](https://teenage.engineering/guides/op-1#envelope) | Link a parameter to the corresponding region of a curve. |
| [OP–1 exercises](https://teenage.engineering/guides/op-1/original/exercises) | Work toward a recognizable result while explaining the components used. |
| [TX–6 signal flow](https://teenage.engineering/guides/tx-6#signal-flow) | Trace one input through a complete processing path. |
| [PO–80 recording](https://teenage.engineering/guides/po-80/en#record) | Enlarge the part involved in one operation and label the action. |

The review surveyed English entries in the [guide catalog](https://teenage.engineering/guides), with representative rendered pages across EP, field, OP, PO/modular, and speaker/accessory families. Computer assembly PDF interiors were only partially accessible. The skill uses the patterns above, not a claim that every page was inspected visually.
