# Forge Workshop Kit 0.1.1 technical preview

Four copyable Forge notebooks: Solar Autoresearch, Pending, Inc., a starter and a read-only facilitator monitor. Participants use their own project and credentials. No workshop gateway or host-issued token.

The release contains a 26.1 MB immutable solar teaching dataset, editable experiment code, direct inference with an $8 adjustable allowance, resumable artifacts, Agent Lens traces, Weave evaluations, a captioned recorded walkthrough and facilitator materials.

Both live rehearsal paths completed. The image model’s final error improved modestly; the measurement model underfit; Pending’s versions tied. Results and failures are retained. Native EvalTables currently returns HTTP 500, so comparisons remain available through Weave and the notebook.

Hosted copy/setup/trace export was verified under a maintainer account. External-attendee and human usability checks remain before classroom-ready status. See [release checks](release-checks.md).
