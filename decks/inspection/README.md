# Visual Inspection companion deck

Edit `scripts/build-storyboard.py`, then run the shared deck build. The deck uses the same controls and function names as `scripts/inspection_cells.py`. Native captures are added only after a successful project publication; the included photographs and masks are actual VisA examples, not product screenshots.

The failed first recipe and the explicitly labeled teaching retest both appear. Local images retain VisA attribution and the source link. Opening the deck does not run training or inference.
